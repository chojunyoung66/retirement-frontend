# 섹션 초안: 주택연금과 정년 연장 대응

> 용도: 정년 65세 연장·퇴직 예정자 대응 보고서 삽입용  
> 기준일: 2026-08-01  
> 근거: 한국주택금융공사, 금융위원회(2026.2.5) 보도자료

---

## 1. 요지

주택연금은 보유 주택을 담보로 제공하고 거주하면서 평생(또는 확정기간) 월 연금을 받는 **국가보증형 주택담보 노후연금**이다. 정부는 이를 국민·퇴직·개인연금에 이은 **다층 노후보장의 네 번째 축**으로 명시한다. 법정 정년(60세)과 국민연금 수급 개시(출생연도별 63~65세) 사이 **소득공백**을 메우는 보완 수단이며, 정년 연장 입법과 직접 연동되지는 않으나 퇴직 시나리오 설계에서 필수 검토 항목이다.

## 2. 가입 요건 (현행)

| 구분 | 요건 |
|------|------|
| 연령 | 부부 중 1인 만 55세 이상 (월지급금은 부부 중 **연소자** 기준) |
| 국적 | 부부 중 1인 대한민국 국민 |
| 주택가격 | 부부합산 **공시가격 12억 원 이하** |
| 다주택 | 합산 12억 이하면 가능 / 초과 2주택은 3년 내 1주택 처분 조건부 |
| 대상주택 | 주택법상 주택, 주거용 오피스텔, 신고된 노인복지주택 |
| 거주 | 원칙 실거주. 2026.6.1부터 질병·봉양·노인복지시설 등 예외(1주택) |

비용(2026.3.1 이후 신규): 초기보증료 주택가격의 **1.0%**(기존 1.5%에서 인하), 연보증료 대출잔액의 **0.95%**. 기존 가입자 소급 없음.

## 3. 지급 구조

**상품:** 일반형 / 우대형(기초연금+시가 2.5억 미만 1주택) / 주담대·소상공인 상환용 / 세대이음  
**방식:** 종신지급·종신혼합 / 확정기간혼합 / 대출상환·우대지급 등  
**유형(종신):** 정액형 · 초기증액형 · 정기증가형  

월지급금은 담보 시세(부동산원→KB→공시/감정), 연소자 연령, 지급방식·유형으로 산정한다. 시세 12억 초과분은 12억 한도. 동일 주택이면 연령이 높을수록 월액이 커진다.

2026년 개선: 계리모형 재설계로 평균 가입자(72세·4억) 기준 월 **129.7→133.8만 원**(+3.13%, 3.1 이후 신규). 우대형은 시가 1.8억 미만 우대폭 확대(6.1 이후 신규).

## 4. 정년 연장과의 관계

```
법정 정년 60세 ──소득공백── 국민연금 수급(63~65세)
        │
        ├ 계속고용·정년연장(입법 논의)
        └ 주택연금(만 55세~) ← 주택 보유 시 월현금 보완
```

- **55~60세:** 정년 전이라도 가입 가능. 연소자가 젊을수록 월액↓ → 조기 가입은 수령기간↑ vs 월액↓ 트레이드오프.
- **60세 정년 직후:** 국민연금 개시 전 공백을 주택 유동화로 보완.
- **정년 65세 연장 시:** 근로소득 유지 기간이 길어져 가입 필요 시점이 뒤로 밀릴 수 있음. 65세 가입은 60세보다 월액이 큼.
- **재고용·임금피크:** 소득 감소분과 주택연금을 병행하는 시나리오가 현실적.

## 5. 퇴직 예정자 권고

1. 가입 가능 여부는 정년과 무관하게 **55세·공시가 12억**부터 점검한다.  
2. 정년~국민연금 공백 구간에 **종신 정액**을 얹어 현금흐름을 안정화한다.  
3. 기존 주담대가 있으면 **상환용 주택연금**으로 이자 부담을 정리하는 선택지를 검토한다.  
4. 정년 연장·재고용 확정 전에는 “즉시 가입”보다 **가입 연령별 월액·상속잔여·실거주**를 시뮬레이션한 뒤 결정한다.  
5. 정확한 월액은 한국주택금융공사 예상연금조회에서 확인한다.

## 6. 한계·주의

- 월액은 가입 시점 고정(집값 상승해도 자동 인상 없음).  
- 누적 채무가 집값을 넘어도 국가 보증으로 추가 청구 없음이 일반적.  
- 상속 가능 지분 = 집값 − 누적 연금채무.  
- 본 섹션은 제도 개요이며, 개별 가입 적격·금액은 공사·금융기관 상담이 필요하다.
